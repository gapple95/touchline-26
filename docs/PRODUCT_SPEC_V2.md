# TOUCHLINE 26 제품 기획 v2

## 1. 제품 정의

TOUCHLINE 26는 실제 FIFA 월드컵 선수 통계를 보존하면서, 사용자가 직접 선수를 배치하고 여러 전술을 경기 중 전환하며 결과를 해석하는 감독 체험 서비스다.

핵심 차별점은 단순 포메이션 보드가 아니라 다음 다섯 요소가 한 흐름으로 연결된다는 점이다.

1. FIFA 공식 통계를 기반으로 한 선수 카드
2. 포지션과 역할에 따른 선수 간 시너지 분석
3. 드래그, 클릭, 배치, 수치 조절을 통한 직접 지휘
4. 자연어를 이해하는 LLM 전술 코치
5. 경기 종료 후 감독의 선택을 평가하는 리포트

## 2. 선수 데이터 원칙

### 공식 데이터는 그대로 저장한다

FIFA 통계 화면의 분류를 데이터 모델의 최상위 기준으로 사용한다.

- 기본: 출전, 선발, 출전 시간, 득점, 도움
- 공격: 슈팅, 유효 슈팅, 박스 안·밖 슈팅, 헤더, xG, 공격 전개 참여
- 배급: 패스, 성공 패스, 성공률, 크로스, 드리블 돌파, 라인 브레이킹 패스, 방향 전환 패스
- 수비: 태클, 인터셉트, 블록, 클리어런스, 공중볼, 소유권 회복
- 규율: 파울, 경고, 퇴장, 오프사이드
- 골키핑: 피유효슈팅, 선방, 선방률, 실점, 클린시트, 골 방지, 배급
- 움직임: 전진 운반, 라인 사이 수신, 활동 구역, 이동 거리
- 피지컬: 최고 속도, 총 이동 거리, 고강도 주행, 스프린트

원시값에는 반드시 출처 URL, 대회, 경기, 수집 시각, 단위를 함께 저장한다. 제공되지 않는 값은 0으로 채우지 않고 `null`로 유지한다.

### 파생 데이터는 공식 통계와 분리한다

포지션 적합도, 역할 적합도, 시너지, 전술 적합도는 서비스가 계산한 값이다. 모든 파생값에는 계산식 버전과 사용한 입력값을 남긴다.

```text
공식 원시 통계 -> 경기당·90분당 정규화 -> 역할별 가중치 -> 포지션 적합도 -> 조합 시너지
```

감독 화면에서는 `FIFA 공식`과 `TOUCHLINE 분석`을 서로 다른 레이블과 색상으로 구분한다.

## 3. 선수 객체화

선수는 단순히 `FW`, `MF`, `DF`, `GK`로만 분류하지 않는다. 한 선수는 여러 포지션과 역할을 동시에 가질 수 있다.

### 위치

- GK: 골키퍼
- CB: 중앙 수비수
- FB/WB: 풀백·윙백
- DM: 수비형 미드필더
- CM: 중앙 미드필더
- AM: 공격형 미드필더
- W: 윙어
- ST: 스트라이커

### 역할

- 골키퍼: 슈퍼 키퍼, 스위퍼 키퍼, 빌드업 키퍼
- 수비: 스토퍼, 커버 수비수, 볼 플레이잉 센터백, 오버래핑 풀백, 인버티드 풀백
- 중앙: 앵커, 볼 위닝 미드필더, 레지스타, 박스 투 박스, 메짤라, 중앙 플레이메이커
- 측면: 터치라인 윙어, 인사이드 포워드, 와이드 플레이메이커, 채널 러너
- 공격: 타깃 포워드, 포처, 프레싱 포워드, 폴스 나인

역할은 공식 통계와 이벤트 데이터를 바탕으로 계산한다. 예를 들어 패스 성공률만 높은 선수를 플레이메이커로 판단하지 않고 라인 브레이킹, 방향 전환, 전진 운반, 압박 상황 패스까지 함께 사용한다.

## 4. 선수 시너지

시너지는 두 선수의 단순 능력치 합이 아니라 포메이션, 역할, 경기 국면, 상대 수비 방식에 따라 달라지는 관계 객체다.

### 대표적인 긍정 시너지

- 와이드 플레이메이커 + 오버래핑 풀백: 한 명이 안쪽으로 들어오면 다른 한 명이 바깥 폭을 제공
- 홀딩 미드필더 + 전진형 8번: 한 명이 공간을 지키고 다른 한 명이 박스 근처로 전진
- 볼 플레이잉 센터백 + 스위퍼 키퍼: 높은 수비선에서 후방 빌드업과 뒷공간 커버 강화
- 타깃 포워드 + 얼리 크로서: 공중볼과 빠른 크로스의 결합
- 창의적 패서 + 채널 러너: 라인 브레이킹 패스와 수비 뒤 침투의 결합

### 대표적인 충돌

- 양쪽 풀백이 동시에 높게 전진하면 역습 방어 인원이 부족해진다.
- 같은 하프스페이스를 선호하는 두 선수를 가까이 배치하면 점유 공간이 겹친다.
- 높은 압박 전술에 압박 가담과 회복 속도가 낮은 선수가 많으면 전술 지속 시간이 짧아진다.

시너지 결과는 공격, 수비, 전환, 빌드업, 세트피스 점수와 함께 `왜 이런 점수인지`를 자연어로 제공한다.

## 5. 직접 조작 경험

### 필수 조작

- 피치 위 선수 드래그앤드롭
- 두 선수를 차례로 클릭해 위치 교환
- 벤치 선수를 피치에 드롭해 교체
- 포메이션 선택 시 선수 좌표 자동 재배열
- 선수 카드 클릭 시 공식 통계와 역할 적합도 비교
- 압박, 수비선, 공격 폭, 템포, 위험도 슬라이더 조절
- 저장된 전술을 한 번의 클릭으로 즉시 전환

드래그가 어려운 모바일과 키보드 환경에서도 동일한 결정을 내릴 수 있도록 클릭 대체 조작을 제공한다.

## 6. LLM 전술 코치

사용자는 자연어로 원하는 축구를 설명한다.

> “후반 70분에 한 골이 필요해. 손흥민이 침투할 공간을 만들고 이강인의 패스를 살려줘.”

LLM은 문장을 다음의 제한된 전술 의도로 변환한다.

- 경기 상태: 시간, 점수 차, 남은 교체
- 우선순위: 득점, 점유, 역습 방지, 체력 보호
- 공격 구역: 좌측, 우측, 중앙, 하프스페이스
- 핵심 선수와 원하는 역할
- 허용 위험도

LLM은 직접 결과를 확정하거나 존재하지 않는 선수·전술을 만들지 않는다. 등록된 선수 ID와 전술 프리셋만 참조해 2~3개의 후보를 만들고, 각 추천에는 이유와 위험을 함께 표시한다. 실제 적용은 사용자가 확인 버튼을 눌러야 한다.

## 7. 다중 전술과 경기 중 전환

감독은 경기 전에 여러 전술을 준비한다.

- CONTROL: 리드 상황에서 점유와 수비 균형 유지
- PRESS: 동점 상황에서 전방 압박과 빠른 재탈취
- CHASE: 후반 열세에서 3-4-3으로 전환해 공격 인원 확대
- PROTECT: 종료 직전 리드 상황에서 라인과 템포 조절

각 전술은 공격·수비·전환·빌드업·세트피스·체력 위험 지표를 가진다. 전술 전환 전후의 지표 차이를 미리 보여주고, 경기 타임라인에는 언제 어떤 전술로 바꿨는지 기록한다.

## 8. 전술 지표

### 공격 지표

- 찬스 생성력
- 박스 진입 가능성
- 폭 활용
- 중앙 침투
- 세컨드 볼 확보
- 역습 속도

### 수비 지표

- 압박 성공 가능성
- 중앙 보호
- 측면 커버
- 뒷공간 위험
- 공중볼 방어
- 전환 방어

### 운영 지표

- 빌드업 안정성
- 전술 지속 가능 시간
- 선수 역할 적합도
- 전체 시너지
- 카드·부상·피로 위험

모든 지표는 0~100으로 표현하되, 원시 통계가 아니라 서비스 파생값임을 명확히 표시한다.

## 9. 경기 종료 후 감독 평가

결과 평가는 승패만으로 감독을 채점하지 않는다.

- 선발 적합도: 선택한 선수와 역할이 경기 계획에 맞았는가
- 전술 전환 타이밍: 점수와 경기 흐름에 맞춰 제때 변경했는가
- 시너지 실현도: 예상한 조합이 실제 장면에서 연결되었는가
- 위험 관리: 공격을 늘리는 동안 역습 위험을 통제했는가
- 교체 영향: 교체 전후 공격·수비 지표가 어떻게 변했는가
- 설명 가능성: 성공·실패 장면을 어떤 결정과 연결할 수 있는가

평가 화면은 종합 등급보다 `좋았던 결정`, `아쉬운 결정`, `다시 한다면`을 먼저 보여준다. 결과와 의사결정을 분리해 운이 좋았던 승리와 내용이 좋았던 패배를 구분한다.

## 10. 감독 성향 카드

감독 성향 카드는 한 경기의 승패가 아니라 반복된 의사결정으로 사용자의 축구 철학을 설명한다. 경기 준비, 교체, 전술 전환, 전술 대결에서 남긴 선택을 누적해 다음 성향을 0~100으로 계산한다.

- 압박 성향: 얼마나 빠르고 높은 위치에서 공을 되찾으려 하는가
- 위험 감수: 득점을 위해 수비 안정성을 얼마나 포기하는가
- 전환 속도: 경기 흐름이 바뀌었을 때 전술을 얼마나 빠르게 수정하는가
- 공격 선호: 폭 활용, 중앙 침투, 역습, 점유 중 무엇을 우선하는가
- 선수 활용: 스타 중심, 역할 적합도 중심, 조합 시너지 중심 중 어디에 가까운가
- 근거 의존도: 추천을 그대로 수용하는지, 수치와 위험을 비교한 뒤 수정하는지
- 추격 방식: 열세에서 공격 숫자, 압박, 템포를 어떤 순서로 높이는가

카드에는 `하이 프레스 설계자`, `중앙 지배형`, `전환 승부사` 같은 대표 아키타입을 붙이되 한 가지 유형으로 사용자를 고정하지 않는다. 각 수치에는 근거가 된 결정 2~3개를 연결하고, 표본 경기 수와 신뢰도를 함께 표시한다. 결과 중심의 능력치나 실력 등급이 아니라 감독의 선택 패턴을 보여주는 카드이며, 경기 후 공유 이미지와 전술 대결 프로필로 사용한다.

## 11. 전술 대결과 1대1 확장

전술 대결은 같은 월드컵 경기 상황을 두 감독에게 제시하고, 제한 시간 안에 내린 선택의 상성을 비교하는 모드다. 축구 액션 게임처럼 90분 전체를 실시간 조작하지 않고 `선발`, `하프타임`, `60분`, `80분` 같은 핵심 의사결정 구간에 집중한다.

### 대결 모드

- AI Duel: 실제 월드컵 데이터로 구성한 가상 상대 감독과 즉시 대결한다. 심사자가 혼자 접속해도 모든 기능을 경험할 수 있는 기본 모드다.
- Ghost Duel: 다른 사용자가 이미 제출한 전술 선택 기록과 비동기로 대결한다. 상대의 접속을 기다리지 않으며, 초대 링크로 같은 시나리오에 도전할 수 있다.
- Live Duel: 익명 닉네임과 6자리 방 코드로 두 사용자가 동시에 참여한다. 회원가입 없이 초대 링크만으로 입장한다.

### 한 라운드의 흐름

1. 두 감독에게 동일한 스쿼드, 상대 데이터, 점수, 시간, 체력 상태와 결정 시간이 주어진다.
2. 각 감독은 선수를 드래그해 배치하고 역할, 전술 프리셋, 공격 방향, 압박 강도를 선택한다.
3. 제출한 선택은 잠그고 상대가 제출하기 전까지 공개하지 않는다.
4. 같은 시뮬레이션 시드로 공격 경로와 수비 커버, 선수 시너지, 체력, 위험도를 계산한다.
5. 결과와 함께 `왜 이 전술이 상대를 공략했는지`, `어디에서 상쇄됐는지`, `다음 라운드에서 무엇을 읽어야 하는지`를 공개한다.
6. 다음 경기 구간으로 이동해 상대의 변화에 다시 대응한다.

### 공정성과 재미 원칙

- 양쪽에 동일한 원본 경기 상태와 선택 시간을 제공한다.
- 같은 입력에는 같은 결과가 나오도록 결정적 시뮬레이션 시드를 사용한다.
- 단순 공격 수치 합산이 아니라 측면 과부하 대 측면 커버, 하이 프레스 대 빌드업 탈압박처럼 전술 상성을 계산한다.
- 연결이 끊기거나 상대가 늦으면 해당 선택을 Ghost로 저장하고 AI가 이어받아 경기를 끝낼 수 있게 한다.
- 대결 결과뿐 아니라 감독 성향 차이를 함께 보여줘 승패 이후에도 비교할 이야기를 만든다.

### 해커톤 구현 범위

- 필수: AI Duel, 감독 성향 카드, 전술 상성 설명
- 권장: Ghost Duel과 공유 가능한 도전 링크
- 확장: 방 코드 기반 Live Duel
- 이후: 공개 매치메이킹, 감독 랭크, 월드컵 시나리오 시즌제

실시간 멀티플레이만을 핵심 진입점으로 두지 않는다. 심사 환경에서는 두 번째 사용자가 없어도 기본 경험이 완결되어야 하며, Live Duel의 서버 연결에 문제가 생겨도 AI 또는 Ghost 상대에게 자동 전환한다.

## 12. PPT 반영 항목
